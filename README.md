Skyward is a polished little flight game in a single self-contained page: fly the red plane as far as you can, thread golden rings to build a combo multiplier, dodge birds, balloons, kites, storm clouds and rock spires, and grab stars to keep your boost meter full. Power-ups (shield, magnet, slow-mo), a full day–sunset–night cycle, parallax mountains, synthesized engine and pickup sounds, keyboard/mouse/touch controls, and a persistent best distance. No external resources, no network, nothing to install.

## Run it

```sh
node main.ts
```
