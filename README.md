Skyway is a small, polished browser flight game: pilot a little red plane
through golden rings, collect stars, grab fuel cans, and dodge mountains,
birds, hot-air balloons and thunderstorms while the sky cycles from day to
dusk to night. Three lives, a combo system for consecutive rings, wind gusts,
a fuel gauge that weakens the engine when empty, and a best score that
persists in the browser. No assets, no network, no dependencies — the whole
game is one self-contained page generated by `main.ts`, with procedural
WebAudio sound for the engine, rings, pickups and crashes.

## Run it

```sh
node main.ts
```

That writes the game to `out/index.html`. Open it in a desktop browser
and fly — no build step, no server, no install.

Controls: hold **Up / W / Space / touch** to climb, **Down / S** to dive,
**Left / Right** (or **A / D**) for slower / faster, **P** to pause,
**M** to mute. Thread rings to build a combo, grab stars for points, and
pick up fuel cans before the tank runs dry.
